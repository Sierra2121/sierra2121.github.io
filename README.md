# 為什麼研究室｜SIERRA

機電研究與知識迴路學習網站。部署在既有 `Sierra2121/sierra2121.github.io` Repository 的 `main` 分支根目錄。

## 使用方式

- 首頁：`/`
- 機電研究：`/mech/`
- 知識迴路：`/knowledge-loop/`

## 更新 GitHub

備份舊網站並解壓本 ZIP。將本 ZIP 的根目錄所有檔案與資料夾上傳到原 Repository 根目錄（不是再包一層資料夾）。覆蓋同名檔案。原有 `diary/`、`seo/`、`why/` 須另外從 GitHub 刪除；上傳 ZIP 不會自動刪除不在 ZIP 裡的檔案。

保留既有 Pages 設定（main / root）。知識迴路的學習紀錄儲存在瀏覽器，跨網域或裝置前可先匯出 JSON 備份，再於新網站匯入，請勿將個人紀錄上傳公開 Repository。
